PROOF OF CONCEPT

An AI Copilot Built Directly Into OMS Order Hub

Challenge. IBM Sterling OMS support work involves generating ad-hoc reports, investigating stuck orders, running inventory analysis, and searching across multiple application and agent logs — then manually correlating data across APIs, database tables, and source code just to reach the actual business root cause.

Approach. Built a proof-of-concept AI support agent embedded directly into Order Hub, not as a separate chatbot. It analyzes application and agent log files across multiple servers simultaneously, investigates stuck orders and inventory-related issues, queries OMS OOB tables and APIs, and reads the project codebase to help surface potential defects.

Outcome. A single, centralized assistant inside Order Hub that consolidates information from logs, data, and code to accelerate root-cause analysis, and assists with support ticket creation and developer Jira stories — instead of manually navigating logs, SQL, code, and documentation across separate tools.
